# Postal — WotLK 3.3.5 Backport

**Оригинальный автор:** Xinhuan  
**Бэкпорт под 3.3.5:** Keoo (Warmane)

> Postal — расширенная поддержка почтового ящика.  
> Оригинальный аддон для Live версии игры был портирован для работы на WotLK 3.3.5.

---

## Возможности

### BlackBook
- Добавляет список контактов рядом с полем «Кому»
- Отслеживает всех ваших персонажей (по мере входа) и показывает их на вкладке «Альты», если они на том же сервере/фракции
- Отслеживает последних 20 получателей в списке «Недавние»
- Автодополнение имён из списков Альтов, Недавних, Контактов
- Возможность отключить стандартное автодополнение Blizzard

### CarbonCopy
- Копирование содержимого письма

### DoNotWant
- Показывает иконку, указывающую, будет ли письмо возвращено или удалено при истечении срока

### Express
- Shift+Клик — взять предмет/деньги из письма
- Ctrl+Клик — вернуть письмо
- Alt+Клик — переместить предмет из сумки в исходящее письмо
- Опция отключения множественных подсказок предметов в письме

### OpenAll
- Открытие всех писем выбранных типов одним нажатием
- Фильтры для аукционных писем (отменённые, истёкшие, перебитые, успешные, выигранные)
- Отдельные настройки для нейтрального и фракционного Аукциона
- Shift+Клик по кнопке OpenAll — открыть все письма, игнорируя фильтры
- Выбор количества свободных слотов в сумках при открытии

### Rake
- Отображает сводку полученных денег из писем

### Select
- Добавляет чекбоксы в инbox с кнопками выборочного открытия/возврата
- Номера писем над чекбоксами
- Shift+Клик по двум чекбоксам — выбрать диапазон
- Ctrl+Клик по чекбоксу — выбрать все письма от этого отправителя

### TradeBlock
- Блокирует приглашения в торговлю и подписание гильдейского устава, пока вы у почтового ящика

### Wire
- Автоматически заполняет тему письма суммой денег, если поле темы пустое

## Установка

1. Скачайте последний релиз
2. Распакуйте архив в `Interface/AddOns/`
3. Убедитесь, что папка называется `Postal`
4. Зайдите в игру и включите аддон
